Xero

A minimal, native, zero-runtime-cost systems language.

Linux & macOS

curl -fsSL https://download.xerolang.org/install.sh | sudo bash

Without root, it installs to ~/.xero: curl -fsSL https://download.xerolang.org/install.sh | bash

Windows (PowerShell)

irm https://download.xerolang.org/install.ps1 | iex

Then

xeroc run hello.xr

The installers download the latest release, verify its SHA-256 checksum, and install clang (Xero's LLVM back end) if it is missing. See INSTALL.md for options.
